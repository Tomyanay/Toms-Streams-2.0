# Tom's Streams 🍳

Welcome to the **Tom's Streams** repository! This project is a modern Streaming website built by: **React and TypeScript (TSX) on vite as a Frontend project**, featuring over 10,000 items to watch whenever you want to.

---

## ✨ Features

* **Watch you favorite items:** Browse over 10,000 Items from 1970 to modern day.
* **Instantaneous Search** Automatically brings up results every time the user types in the search input .
* **Item Information** Discover each item rating,summery,status and more. 
* **Locally Saved** Every change you make will automatically save in the browser so when you re enter the website you will be able to continue where you left off
* **Modern UI** The website was modified so the UI will be smooth and quick and user friendly to the user

---

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Tomyanay/Toms-Streams-2.0.git

2. **Enter your project folder:**

   ```bash
   cd Toms-Streams-2.0
   
3. **Install dependencies:**

   ```bash
   npm install
 
4. **Run the project locally on dev server:**

   ```bash
   npm run dev
